# Quiz App

An interactive quiz application where users can answer multiple-choice questions and receive a score at the end.

## Description

This project is a simple quiz application built to practice JavaScript logic and user interaction.

Users can answer a series of questions and receive their score at the end of the quiz.

## Features

- Multiple choice questions
- Score tracking
- Interactive UI
- Dynamic question logic

## Technologies Used

- JavaScript
- HTML
- CSS
- Git

## Installation

Clone the repository:

git clone https://github.com/erikgor00/Quiz-App.git

Install dependencies:

npm install

Run the app:

ng serve

Open:

http://localhost:4200
